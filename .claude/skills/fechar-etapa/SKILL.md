# Fechar etapa

Use esta skill somente quando uma tarefa importante tiver sido efetivamente concluída e validada.

## Não usar para

- perguntas, explicações, análises, planejamento, propostas;
- testes isolados, commits, pequenas correções;
- tarefas ainda não confirmadas.

## Procedimento

1. Confirme que a entrega foi concluída e verificada.
2. Não edite nenhum outro arquivo automaticamente.
3. Produza o fechamento no formato abaixo.

## Formato do fechamento

**Concluído:** ...

**Decisões permanentes tomadas:** ... (ou "nenhuma")

**Arquivos alterados:** ...

**Testes/verificações realizados:** ...

**Pendências:** ... (ou "nenhuma")

**Próxima tarefa recomendada:** ...
